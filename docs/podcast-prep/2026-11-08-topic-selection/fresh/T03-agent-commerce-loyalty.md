# T3. Лояльность, когда покупает агент: что вышло с 31.10 по 07.11.2026

## Новое

1. **Amazon, 06.11.** Alexa for Shopping принимает заказы текстом, есть автопокупка по цене. Приглашения в США, скоро «миллионы». [Digiday](https://digiday.com/media-buying/amazons-shopping-agent-now-takes-orders-by-text-with-sponsored-product-ads-in-the-replies/): Sponsored Products в ответах, пока бесплатно; покупки, завершённые агентом, без рекламы. [PPC Land](https://ppc.land/amazons-alexa-for-shopping-takes-orders-by-text-invite-only-for-now/): Amazon о рекламе в переписке не говорил. Пресса. Новый повод.
2. **Amazon, 04.11.** Shop Direct Merchant Workspace, бесплатный портал: магазины вне Amazon в поиске и Alexa for Shopping, Buy for Me покупает у них; США. [Документация](https://developer-docs.amazon/sp-api/docs/shop-direct) (вендор), [PPC Land](https://ppc.land/amazons-new-portal-lets-any-eligible-store-list-in-its-search-for-free/) (пресса). Новый повод.
3. **Shopify, 03.11.** ИИ-заказы ×3,3, трафик ×2,6, база не раскрыта, объём «still small». Впервые делегированные покупки через личных агентов. Shop — «your complete buyer profile». [Стенограмма](https://singjupost.com/?p=65039) (сторонняя), [PPC Land](https://ppc.land/shopify-revenue-gains-32-to-3-7bn-as-ai-referred-orders-rise-3-3x/) (пресса); в [8-K](https://www.sec.gov/Archives/edgar/data/1594805/000159480526000067/exhibit991pressreleaseq320.htm) ИИ-метрик нет. Меняет факт.
4. **Personal Agent Protocol.** [Спецификация](https://personalagentprotocol.org/docs/0.4/spec) уже Draft 0.4, [коммиты](https://github.com/personal-agent-protocol/personal-agent-protocol) 05–07.11. Вендор. Программ лояльности нет. Sierra и Meta на сайте не названы, связь — по [Forkast](https://forkast.news/?p=131910). Меняет факт.
5. **Marriott, 02.11.** Капуано: ИИ пока влияет в основном на выбор, не на бронирование; Bonvoy: 309 млн участников. [Hotel Dive](https://www.hoteldive.com/news/marriott-focuses-ai-loyalty-tech-enhances-experiences/873571/), пресса. Контекст.
