# Episode prep template / Шаблон подготовки выпуска

Use this checklist to draft a brief that can be shared with listeners before recording. Publish it as a JSON file modeled on [the infrastructure brief](agent-development-infrastructure.json).

1. Match `topic` to the map node ID. Give the file a stable `slug`.
2. Write a title, one-sentence description, opening example and a short list of discussion questions in English and Russian.
3. Link a public background article in `source` (a locale-free path on polomodov.tech). Check that both language pages exist.
4. Check names, claims and references against primary sources before publication.
5. After release, connect the same map node to the published episode ID and keep the prep link for context.

В обеих версиях сохраните одни и те же вопросы в одном порядке. В публичный файл идут только формулировки и ссылки, которые уже можно показать слушателям.
